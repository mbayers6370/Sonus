# Sonus Data Archive

## Purpose
This directory contains archived language/data assets kept for historical reference.

The active application implementation is maintained in:
- `../sonus-react/` (current frontend)
- `../backend/` (current API)

## Contents

### Language Track Definitions
- `data/languages.js` - language metadata archive
- `data/tracks-jp.js` - JLPT track definitions archive
- `data/tracks-kr.js` - TOPIK track definitions archive
- `data/tracks-fr.js` - CEFR track definitions archive

## Notes
- This directory is archival/reference-oriented.
- Active product behavior and schema ownership live in the app directories.
